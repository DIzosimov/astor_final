# ASTOR: A Program Repair Library for Java

ASTOR is an automatic software repair framework developed collaboratively by Inria, the University of Lille, Université Polytechnique Hauts-de-France, and KTH Royal Institute of Technology. The acronym stands for "Automatic Software Transformations fOr program Repair."

## Core Citation

The foundational publication is Martinez and Monperrus's 2016 ISSTA paper, "ASTOR: A Program Repair Library for Java," which introduced the framework to the research community.

## Main Repair Approaches

ASTOR implements multiple repair strategies:

- **jGenProg**: An implementation of the GenProg algorithm
- **jKali**: Based on the Kali repair technique
- **jMutRepair**: Leverages mutation-based repair strategies
- **DeepRepair**: Extends jGenProg using code similarity analysis
- **Cardumen**: Employs automatically mined repair templates
- **3sfix**: Selects repair ingredients based on similarity metrics

## Contributors & Leadership

The project is led by Matias Martinez and includes contributions from Martin Monperrus, Thomas Durieux, Martin G. White, Claire Le Goues, Simon Urli, and Yi Wu across multiple institutions.

## Educational Use

ASTOR has been integrated into software engineering courses at institutions including Humboldt-Universität zu Berlin and TU Delft, demonstrating its value for academic instruction in program repair techniques.
